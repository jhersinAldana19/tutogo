# TutoGo — landing

Landing comercial de TutoGo. Fuente de contenido: *TutoGo Sales Book 2026*.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Contenido y recursos

- Textos y cifras: `src/content/site.js`
- Contacto (aún vacío): `src/content/contact.js`
- Logo oficial: `src/content/assets.js`
- Colores extraídos del PDF: `src/styles/tokens.css`

Ver `RESOURCES.md` para lo que todavía falta.
